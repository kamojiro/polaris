# NNNN. (決定を表す短いタイトル、体言止めではなく「〜を採用する」のような動詞形で)

## ステータス

提案中 / 採択 / 却下 / 廃止(supersedes ADR-XXXX) / 置き換え(superseded by ADR-XXXX)

## コンテキスト

なぜこの決定が必要になったか。制約・背景・関連する要求を書く。「何を選んだか」ではなく「なぜ選ぶ必要があったか」に集中する。

## 決定

何を決定したか。1〜2文で明確に言い切る。

## 検討した代替案

- 案A: 概要と、採用しなかった理由
- 案B: 概要と、採用しなかった理由

## 結果(Consequences)

この決定によって何が得やすくなるか、何を犠牲にするか。良い面・悪い面の両方を書く。後から見て「この決定のトレードオフは何だったか」が分かることが目的。
